# 🛒 বাজার দর | BazarDor

## 📌 Project Description

**BazarDor (বাজার দর)** is a responsive web application that helps users explore daily market prices of essential products in Bangladesh. Users can check product prices, compare minimum and maximum prices across different markets, and track price changes to make better shopping decisions.

## 🚀 Technologies Used

- **Next.js 15** – React framework
- **React** – UI development
- **TypeScript** – Type-safe development
- **Tailwind CSS** – Styling
- **DaisyUI** – UI components
- **MongoDB** – Database
- **Better Auth** – Authentication
- **Lucide React** – Icons
- **React Hot Toast** – Notifications

## ✨ Key Features

1. **Daily Market Prices** – View the latest prices of essential products in Bangladesh.
2. **Product Details** – Explore detailed product information, including today's price, minimum price, maximum price, and average price.
3. **Market Price Comparison** – Compare minimum and maximum prices across different markets.
4. **User Authentication** – Secure sign-up and sign-in functionality with Better Auth.
5. **Responsive Design** – Enjoy a smooth experience on desktop, tablet, and mobile devices.
